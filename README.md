# ChromeProfiler — downloads

Native macOS menu-bar app that manages, groups, and launches many Chrome
profiles: instant list/launch, user-defined groups with bulk open, profile
create/rename/delete, and a default-browser link router.

## Install

**[⬇ Download the latest release](https://github.com/namdseasygoingvn/chrome-profiler-dist/releases/latest)**

1. Download `ChromeProfiler.dmg` and drag the app into **Applications**.
2. Launch it — a **▸ icon** appears in the menu bar (no Dock icon).
3. **First open:** macOS blocks the unsigned app — right-click it → **Open → Open**. After that it opens normally.

Once installed, the app keeps itself current (menu ▸ *Check for Updates…*).
